ANEMIALENS WEB - CARA MENJALANKAN
==================================

A. DI LAPTOP (paling stabil untuk demo)
---------------------------------------
1. Pastikan Python 3.11 atau 3.12 terpasang (python.org, centang "Add python.exe to PATH").
2. Klik dua kali  Jalankan_AnemiaLens_Web.bat  di folder AnemiaLens.
   - Pertama kali: memasang paket (5-10 menit, butuh internet). Berikutnya langsung jalan.
   - Browser terbuka otomatis ke http://localhost:8000
3. Buka dari HP (WiFi yang sama): lihat alamat "Dari HP" di jendela hitam,
   misalnya http://192.168.1.5:8000. Jika Windows Firewall bertanya, pilih Allow.
4. Untuk berhenti: tutup jendela hitam (atau tekan Ctrl+C).

Model dibaca dari:  AnemiaLens\hasil_model_v2\model\
(ganti model: ekstrak AnemiaLens_model.zip baru ke folder itu, atau jalankan
 web\server.py --model <folder-model>)

B. DI GOOGLE COLAB (link HTTPS publik, bisa dibuka HP mana pun)
---------------------------------------------------------------
1. Buka AnemiaLens_Web_Colab.ipynb di Colab, Runtime > Run all.
2. Upload AnemiaLens_model_v3.zip saat diminta (atau biarkan otomatis bila
   notebook training masih aktif di sesi yang sama).
3. Salin link https://....trycloudflare.com yang muncul, buka di HP.
   Link berlaku selama sesi Colab aktif.

STRUKTUR FILE
-------------
web\server.py          server FastAPI: halaman web + API /api/analyze, /api/info
web\static\            tampilan (index.html, style.css, app.js)
web\requirements.txt   daftar paket (scikit-learn >= 1.6.1, mendukung Python 3.14)
web\preview\           screenshot tampilan untuk proposal/pitch deck
anemialens\            kode model (segmentasi, fitur warna, CNN, pengaman ROI)
hasil_model_v2\model\  model aktif (segmentasi v2 robust + penilai anemia)
arsip_backend_lama\    backend & model segmentasi v1 sebelum pembaruan (cadangan, jangan dipakai)
AnemiaLens_Latih_Ulang_Segmentasi.ipynb   latih ulang U-Net robust di Colab

CATATAN
-------
- Foto tidak disimpan di server; riwayat hanya tersimpan di browser perangkat itu.
- Dokumentasi API otomatis: http://localhost:8000/api/docs
